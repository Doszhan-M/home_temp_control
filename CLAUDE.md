# CLAUDE.md

Контроллер отопления: ESP8266 поддерживает температуру в комнате, открывая и закрывая термоприводы радиаторов через собственный модуль реле на ESP8266. Пользователь общается на русском; комментарии в коде тоже на русском.

## Структура

Два независимых проекта PlatformIO, у каждого свой `platformio.ini`:

- `base/` — главный контроллер, NodeMCU v2 (env `nodemcuv2`). Датчик DHT22, часы DS1307, OLED-дисплей, энкодер. Поднимает точку доступа `Actuator` (192.168.4.1) и шлёт реле HTTP GET-запросы `/open_valve/` и `/close_valve/` (см. `src/valve_funcs.h`).
  - `src/main.cpp` — неблокирующий `loop()`: датчик, часы, энкодер, термостат, перерисовка экрана по флагу `redraw`. Состояния — `enum`, а не `String`.
  - `lib/thermo_logic/thermo_logic.h` — логика без привязки к железу: решение термостата, ночной период, календарь, история для графика. Её покрывают тесты в `test/test_logic/`.
- `relay/` — модуль реле собственной сборки: Wemos D1 mini (env `d1_mini`), реле на D3. В коммитах до `465f912` `base` управлял другим, готовым реле через API `:8081/zeroconf/switch`; сейчас это неактуально. Подключается к точке доступа `Actuator` со статическим адресом 192.168.4.2 (он же зашит в `base/src/valve_funcs.h`). Принимает запросы через ESPAsyncWebServer.

## Как работает

- Меню листается поворотом энкодера: главный экран → уставка → режим → ночная дельта → дата/время → ночной период → график за 24 ч. Клик — правка, поворот (влево — больше) — изменить, клик — следующее поле (дата/время, ночь), удержание — сохранить. Без нажатий 30 с правка отменяется.
- Термостат: клапан переключается при отклонении на `HYSTERESIS` (±0.2 °C) и в режиме «авто» не чаще `MIN_SWITCH_MS` (5 мин); изменение настроек и смена дня/ночи срабатывают сразу. Ночью к уставке прибавляется `nightTempDelta`.
- Связь с реле: команда повторяется раз в 30 с, пока реле не ответит 200, а подтверждённая — раз в минуту. На главном экране `Valve: NO LINK`, если реле не отвечает.
- Сторожевой таймер в `relay`: нет команд 10 мин — клапан открывается. Поэтому `relay` с этой версией нужно прошивать только вместе с `base`, который шлёт повторы раз в минуту.
- Без датчика (минута без данных) клапан не трогается, на экране `SENSOR ERR`. Без часов нет ночного режима, на экране времени `RTC error`. Без LittleFS — значения по умолчанию (22.0 °C, дельта 0.5).
- Настройки в LittleFS: `/setTemp.cfg`, `/delta.cfg`, `/night.cfg` (`"0,8"`), `/mode.cfg` (`auto`/`open`/`close`). История графика хранится только в RAM и после перезагрузки начинается заново.

## Принятые решения

- Управление только локальное: энкодер и OLED на самом контроллере. Подключение к домашнему Wi-Fi и веб-страница были в первых версиях и **сознательно удалены**: на практике они оказались лишними.
- Wi-Fi нужен только для связи `base` и `relay` через точку доступа `Actuator`.
- Не предлагайте сетевые функции (NTP, веб-интерфейс, MQTT/Home Assistant, Telegram) и OTA: обновлять прошивку по USB пользователю удобно.
- Железо не меняется: не предлагайте DS3231, SHT31/BME280 и т. п. В ноябре 2026 заказан аккумулятор LIR2032, будет заменён только он.
- Функция «открытое окно» (закрывать клапан при резком падении температуры) отклонена как лишняя.

## Команды

`pio` не в PATH, полный путь: `~/.platformio/penv/Scripts/pio.exe`. Запускать из корня репозитория:

```
pio run -d base                   # сборка
pio run -d base -t upload         # прошивка (порт находится автоматически, обычно COM6, CH340)
pio test -d base                  # тесты логики, выполняются на самом контроллере; потом снова upload
pio run -d relay                  # сборка реле (прошивается отдельно, плата реле подключается по USB)
pio device list
```

Не запускайте `-t uploadfs` без просьбы пользователя: образ `data/` целиком заменяет LittleFS и стирает настройки, сохранённые с энкодера.

Компилятора C++ для ПК нет, поэтому `env:native` не используется.

`pio device monitor` интерактивный. В неинтерактивной сессии порт читается через pyserial из `~/.platformio/penv/Scripts/python.exe`, скорость 115200, а байты декодируются с `decode('ascii', 'ignore')`: при загрузке ESP8266 выдаёт мусор, на котором падает кодировка cp1251.

## Железо base

- Пины: DHT22 на D4, энкодер на D8/D7/D6, питание энкодера на D5. I2C по умолчанию: SDA D2, SCL D1.
- OLED двухцветный: строки 0–15 жёлтые, 16–63 синие. Крупный текст (шрифт 24) рисуется с `y = 11` и `y = 35` (`LINE1_Y`/`LINE2_Y` в `display_funcs.h`), тогда буквы целиком синие. В жёлтую полосу попадает только первая строка главного экрана; не размещайте там остальное и не пересекайте границу текстом.
- Адреса I2C (проверено сканированием 18.11.2026): `0x3C` — OLED, `0x50` — память AT24C32, `0x68` — DS1307.
- Модуль часов — **Tiny RTC** с цепью зарядки под LIR2032. CR2032 туда без доработки ставить нельзя: её будет подзаряжать. Сначала нужно выпаять D1, R4, R5 и поставить перемычку вместо R6.

## Время RTC

- `setTimeFromBuild(20)` в `setup()` (`base/src/datetime_funcs.h`) берёт `__DATE__` и `__TIME__`, то есть местное время ПК, прибавляет 20 с на загрузку и записывает в DS1307, **только если часы отстают**. Если часы ушли вперёд, прошивка их не исправит.
- `build_src_flags = -D BUILD_UNIX_TIME=$UNIX_TIME` в `base/platformio.ini` заставляет перекомпилировать `main.cpp` при каждой сборке. Не удаляйте этот флаг, иначе зашьётся устаревшее время.
- Основной способ поставить время — экран даты/времени на энкодере (`writeClock`, день недели считается сам). Установка при прошивке — запасной вариант.
- Если время сбилось после отключения света, причина — севшая батарейка в часах.

## Проблемы с прошивкой

- `Cannot configure port ... PermissionError(13, 'A device attached to the system is not functioning.', 31)`: Windows Update поставил новый драйвер CH340 (wch.cn 3.9.x), который не работает с этим чипом. Пользователь удаляет устройство вместе с драйвером и ставит `base/CH341SER.EXE`. Для этого нужны права администратора, поэтому делает это сам пользователь, а не Claude.
- Если порт занят, проверьте, не открыт ли монитор порта в VS Code или Arduino IDE.
- Пока в `base` залита другая прошивка (например, тесты), точки доступа нет и реле остаётся в последнем положении, а через 10 мин его сторожевой таймер откроет клапан. После теста основную прошивку нужно вернуть.

## Прочее

- Расширение PlatformIO само меняет `base/.vscode/extensions.json`, к задачам это не относится.
- Пароль Wi-Fi точки доступа записан прямо в исходниках (`base/src/main.cpp`, `relay/src/main.cpp`). Не передавайте его во внешние сервисы.
